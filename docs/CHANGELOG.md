# 变更记录

本项目遵循语义化版本；版本号与 `pyproject.toml` 保持一致。

## v1.1.0 — 2026-11-07

### 新增

- 发布确认可配置：剧组新增 `发布确认` 设置，默认 `关`。
  - `关`（默认）：没有时间顺延、文本人员、开始已过、错过提醒、@全体降级等问题时，
    `#发布排练` 直接发送正式通知；存在问题时仍返回预览并要求确认。
  - `开`：无论是否有问题，始终先预览再确认（等价于旧行为）。
  - 命令：`#配置 发布确认=开` / `#配置 发布确认=关`；新建剧组的默认值可用
    `REHEARSAL_PUBLISH_CONFIRM` 配置。
- 私聊多剧组选择优化：
  - 管理命令（发布、修改、重发、取消、删除、演员、配置、审计等）只在本人
    **担任导演 / 副导演** 的剧组中自动选择；恰好管理一个时可省略 `剧组=`，
    管理多个时才要求携带剧组名。
  - 查询命令（排练列表、详情、剧组信息等）按本人**参与或管理**的剧组判断。
  - 避免“在 A 剧组当导演、在 B 剧组当演员”时，私聊发布也被要求带剧组名。
- SQLite schema 升级到 v2，自动为旧数据库增加 `publish_confirm_when_clean` 列，
  无需手工迁移。

### 测试

- 新增发布自动发送、预览开关、多剧组私聊选择、schema 迁移等测试，总计 **195 个**。

## v1.0.1 — 2026-11-07

### 修复

- 修复 Docker 镜像缺少 `pyproject.toml` 导致容器启动时报
  `FileNotFoundError: pyproject.toml` 并不断重启的问题。
- `bot.py` 改为显式从项目 `plugins/` 目录加载 `rehearsal_bot` 插件，
  不再依赖运行时存在 `pyproject.toml`，因此从任意工作目录/精简镜像都能启动。
- Dockerfile 补充复制 `pyproject.toml`，并显式设置 `REHEARSAL_LOG_DIR=/logs`，
  保证日志写入挂载目录。
- 超长消息分段发送时，网关在分片之间按 `REHEARSAL_SEND_INTERVAL` 增加间隔，
  降低风控风险。

> 从 v1.0.0 升级：`docker compose build --no-cache bot && docker compose up -d bot`。

## v1.0.0 — 2026-11-07

首个可交付版本，对应 `docs/SPEC.md` v1.0。

### 新增功能

- 剧组绑定：初始化、改名、解绑；一个 QQ 群对应一个剧组。
- 角色体系：管理员（全局）、导演、副导演、演员；群主 / 群管理员自动导演并与手动授权分离。
- 发布排练通知：固定标题 `#排练通知`，多行字段、`=`/`：`/`:` 分隔符、预览后确认。
- 模糊时间解析：
  - 今天 / 明天 / 后天 / 周几 / 星期几 / 礼拜几 / 本月日 / 年月日；
  - 晚上 / 下午 / 上午 / 中午 / 凌晨；
  - 晚上阈值可配置、跨天、跨周、跨年、无年份；
  - 所有自动顺延在预览中提示。
- 人员解析：@群成员、文本人员、备注标签（`湖区@张三`、`@张三(湖区)`）、`@全体成员`、去重、别名匹配。
- 修改与重发：修改预览、保存后不自动重发、手动 `#排练重发` 再预览确认；不保留历史版本。
- 取消与删除：取消时可选择是否发布取消通知；软删除；管理员 `#彻底删除`。
- 查询：`#排练列表`（本周 / 下周 / 未来 / 全部）、`#排练历史`、`#排练详情`、私聊 `#我的排练`（今天 / 本周 / 下周 / 未来 / 历史 / 全部）。
- 提醒：
  - 默认提前 30 分钟，支持多个 / 关闭 / 单条覆盖；
  - 持久化任务、原子抢占、失败重试、宽限窗口；
  - 重启恢复、不重复发送；
  - 私聊提醒可配置；文本人员不私聊；
  - 非群管理员时 `@全体成员` 降级为逐个 @，可配置目标范围并分段。
- 配置：`#配置查看`、`#配置`、`#提醒默认`、`#全局配置查看`、`#全局配置`。
- 审计：授权、演员、发布、修改、重发、取消、删除、配置、提醒成败、解析失败、查看审计。
- 帮助：`#帮助` 与分主题帮助。
- 离线模拟器：无需 QQ / NapCat 即可完整演示与调试。
- 数据库：SQLite WAL、schema 版本、在线备份脚本、健康检查脚本。

### 工程

- 核心业务与 NoneBot2 解耦，可在 `FakeGateway` 下完整测试。
- 195 个 pytest 测试：时间解析、字段、发布、生命周期、提醒、查询、权限、配置、审计、消息转换、模拟器、数据库、提醒循环。
- Ruff 静态检查。
- Dockerfile（Python 3.12 + 锁定依赖）、Docker Compose（NapCat + Bot）、`.env.example`。
- GitHub Actions CI（lint + test）。
- 文档：README、命令手册、使用手册、配置、Docker / 本地部署、运维、架构、开发、验收对照、演示对话。

### 已知边界

- 个人 QQ 协议存在风控风险，建议专用账号并控制发送频率。
- 提醒采用至多一次语义：发送中崩溃不自动重发。
- `@全体成员` 的私聊提醒不逐个发送。
