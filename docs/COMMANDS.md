# 命令手册

本文档覆盖全部可用命令、字段语法、权限要求与错误提示。所有命令默认以 `#` 开头（可通过 `REHEARSAL_COMMAND_PREFIX` 修改）。

相关文档：[使用教程](USAGE.md) · [配置说明](CONFIGURATION.md) · [权限设计](ARCHITECTURE.md#6-权限模型)

---

## 1. 通用约定

### 1.1 命令格式

```text
#命令 参数
```

- 命令与参数之间用空格或换行分隔；
- 多行内容作为同一条 QQ 消息发送；
- 机器人只响应已注册命令，普通聊天不会被误触发；
- 群内命令在绑定剧组的群使用；私聊命令需要机器人能私聊到你。

### 1.2 私聊如何指定剧组

私聊时是否需要 `剧组=`，取决于你与剧组的关系：

- **管理命令**（发布、修改、重发、取消、删除、演员、配置、审计等）：
  只在**你有导演 / 副导演角色的剧组**中自动选择。
  - 恰好管理一个剧组：可省略 `剧组=`；
  - 管理多个剧组：必须用 `剧组=名称` 指定；
  - 没有管理角色：会提示“还没有管理任何剧组”。
- **查询命令**（排练列表、排练详情、剧组信息等）：
  按你**参与或管理**的剧组判断；多个时同样需要 `剧组=名称`。

```text
#发布排练 剧组=剧组A
时间=周五7~10
人员=@张三
```

```text
#排练列表 剧组=剧组A 本周
```

`剧组=` 可以放在命令后的任意位置。若存在多个可选剧组且未指定，机器人会列出名称并提示补上。

> 例：你在 A 剧组是导演、在 B 剧组只是演员，私聊 `#发布排练` 会自动使用 A，不需要带剧组名；
> 但私聊 `#排练列表` 会因为你同时参与 A、B 而要求指定 `剧组=`。

### 1.3 字段分隔符

`时间`、`地点` 等字段支持三种分隔符，完全等价：

```text
地点=一排
地点：一排
地点:一排
```

### 1.4 空值

以下值视为空，不显示：

```text
（空）、暂无、无、-、—、－、空、none、null、n/a
```

### 1.5 @ 成员

- 发布时直接 @ 群成员，机器人会识别为精确提醒对象；
- 也可以输入文本 `@张三`，机器人会按群成员昵称 / 群名片 / 演员别名尝试匹配；
- 无法匹配的文本（如 `制作组`）会作为文本人员展示，不能 @、不能私聊提醒。

## 2. 权限矩阵

| 功能 | 演员 | 副导演 | 导演 | 管理员 |
|---|---:|---:|---:|---:|
| 接收通知 / 提醒 | 是 | 是 | 是 | 是 |
| 查看本剧组排练 / 历史 / 按周 | 是 | 是 | 是 | 是 |
| 查看演员列表 | 否 | 是 | 是 | 是 |
| 私聊查询本人跨剧组安排 | 是 | 是 | 是 | 是 |
| 发布 / 修改 / 重发 / 取消 / 删除通知 | 否 | 是 | 是 | 是 |
| 添加 / 移除演员、维护别名标签 | 否 | 是 | 是 | 是 |
| 配置提醒、私聊提醒、晚上阈值等 | 否 | 是 | 是 | 是 |
| 查看审计日志 | 否 | 是 | 是 | 是 |
| 同步群成员 | 否 | 是 | 是 | 是 |
| 授权 / 取消副导演 | 否 | 否 | 是 | 是 |
| 授权 / 取消导演 | 否 | 否 | 否 | 是 |
| 授权 / 取消管理员 | 否 | 否 | 否 | 是 |
| 修改剧组名称 / 解绑剧组 | 否 | 否 | 否 | 是 |
| 彻底删除排练 | 否 | 否 | 否 | 是 |
| 修改全局配置 | 否 | 否 | 否 | 是 |
| 初始化剧组 | 群主（默认允许） | 否 | 否 | 是 |

> 「初始化剧组」默认允许群主自助执行，便于首次建组；可将 `REHEARSAL_ALLOW_OWNER_INIT` 设为 `false` 改为仅管理员。

角色说明：

- **管理员**是全局角色，可管理所有剧组；
- **导演 / 副导演 / 演员**按剧组授予；
- **群主、QQ 群管理员**自动获得该剧组导演角色；失去群身份时自动撤销，手动授予的角色不受影响；
- 普通群成员在剧组内的展示角色为「演员」。

## 3. 基础命令

### `#帮助` / `#命令列表`

显示帮助概览（含当前剧组、你的角色、命令前缀）。

```text
#帮助
#帮助发布排练
#帮助查询排练
#帮助修改排练
#帮助提醒配置
#帮助权限
#帮助剧组
#帮助演员
#帮助配置
#帮助预览
```

### `#剧组信息`

查看当前剧组的名称、群号、时区、默认提醒、私聊提醒、晚上阈值、显示标签、我的角色。

```text
#剧组信息
```

## 4. 剧组管理

### `#初始化剧组 名称`

在群内把当前 QQ 群绑定为一个剧组。一个群只能绑定一个剧组。

```text
#初始化剧组 某某剧组
```

- 管理员可执行；
- 当 `REHEARSAL_ALLOW_OWNER_INIT=true`（默认）时，群主也可自助初始化，便于首次上手；
- 初始化后群主自动成为导演，可在群内继续授权副导演；
- 已解绑的群可由管理员重新执行本命令绑定，历史数据保留；重新绑定后需对相关排练执行 `#排练重发` 才能恢复提醒。

### `#修改剧组名称 新名称`

管理员修改剧组名称。

```text
#修改剧组名称 某某剧组（新）
```

### `#解绑剧组`

管理员解绑当前群。解绑后：

- 停止所有未发送提醒；
- 历史数据保留；
- 只能查询，不能再发布 / 修改；
- 重新启用需要管理员重新初始化（建议先备份）。

```text
#解绑剧组
```

## 5. 角色管理

### 授权 / 取消副导演

导演或管理员执行。

```text
#授权副导演 @张三
#取消副导演 @张三
```

### 授权 / 取消导演

仅管理员执行。

```text
#授权导演 @张三
#取消导演 @张三
```

> 如果目标是群主 / 群管理员，其自动导演身份无法手动取消；需先在 QQ 群内调整其群管理身份。

### 授权 / 取消管理员

仅管理员执行，QQ 号可跨群全局生效。

```text
#授权管理员 123456789
#取消管理员 123456789
```

- 不能取消唯一的管理员；
- 初始管理员通过 `.env` 的 `REHEARSAL_ADMINS` 指定。

## 6. 演员管理

演员表用于把文本名字 / 别名映射到 QQ 成员。**每次排练的参与人员可以不同于演员表**。

### `#添加演员`

```text
#添加演员 @张三
#添加演员 制作组
#添加演员 @张三 标签=湖区
```

- @ 成员 → 可精确提醒的演员；
- 纯文本 → 文本人员，仅展示，不能 @ / 私聊；
- 可选 `标签=` 设置初始备注标签。

### `#移除演员`

```text
#移除演员 @张三
#移除演员 制作组
```

移除只影响演员表，不删除历史排练参与记录。

### `#演员列表`

导演、副导演、管理员可用。

```text
#演员列表
```

分别列出群成员演员（含 QQ、别名、标签）与文本人员。演员列表包含 QQ 号，因此仅对管理角色开放。

### `#演员别名`

设置（替换）别名，多个用空格 / 顿号分隔；不填参数则查看当前值。

```text
#演员别名 @张三 小张 老张
```

别名可用于发布时的人员匹配：

```text
人员=小五 制作组
```

### `#演员标签`

设置（替换）备注标签；标签默认不在通知中显示，可通过 `#配置 显示标签=开` 打开。

```text
#演员标签 @张三 湖区
#演员标签 @张三
```

## 7. 发布排练通知

### 7.1 主命令与别名

```text
#发布排练
```

别名：`#排练通知`（有字段时等价于发布；群内仅发送标题不会触发发布）。

### 7.2 字段

| 字段 | 必填 | 说明 |
|---|---:|---|
| 时间 | 是 | 支持模糊时间，见第 11 节 |
| 地点 | 否 | 可为空 / 暂无 |
| 人员 | 是 | @群成员、文本人员、`@全体成员` |
| 内容 | 否 | 多行，支持自动编号 |
| 备注 | 否 | 补充说明 |
| 提醒 | 否 | 如 `30`、`60,30,10`、`关闭`；默认使用剧组配置 |
| 通知范围 | 否 | `全体成员` = 提醒全群；默认仅参与人员 |
| 剧组 | 否 | 仅私聊发布时用于指定剧组 |

### 7.3 标准写法

```text
#发布排练
时间=周五7~10
地点=一排
人员=@冯然 @关静一 制作组
内容=
1. 福临门开场和声
2. 一念一宇宙
备注=其他演员可以来自由练习
提醒=30
通知范围=全体成员
```

单行写法也支持：

```text
#发布排练 时间=周五7~10 地点=一排 人员=@张三 @李四
```

### 7.4 发布确认与直接发布

发布行为由剧组配置 `发布确认` 控制，默认 **关**：

| 情况 | 默认行为（发布确认=关） | 发布确认=开 |
|---|---|---|
| 没有任何需要注意的问题 | **直接发送**正式通知，并回复编号 / 提醒信息 | 返回预览，确认后发送 |
| 时间被自动顺延、跨天、跨周、跨年 | 返回预览，确认后发送 | 返回预览，确认后发送 |
| 未填写结束时间（按默认 2 小时） | 返回预览，确认后发送 | 返回预览，确认后发送 |
| 开始时间已过 | 返回预览，确认后发送 | 返回预览，确认后发送 |
| 已错过部分提醒 | 返回预览，确认后发送 | 返回预览，确认后发送 |
| 有文本人员无法精确匹配 | 返回预览，确认后发送 | 返回预览，确认后发送 |
| `@全体成员` 但机器人非群管理员 | 返回预览，确认后发送 | 返回预览，确认后发送 |

修改配置：

```text
#配置 发布确认=开     # 总是预览确认
#配置 发布确认=关     # 无问题直接发布（默认）
#配置 发布确认=自动   # 同“关”
#配置 发布确认=总是   # 同“开”
```

需要预览时，会返回：

```text
【发布预览】
标题：#排练通知
时间：2026-11-13 周五 19:00-22:00
地点：一排
人员：@冯然 @关静一 制作组
内容：
1. 福临门开场和声
2. 一念一宇宙
备注：其他演员可以来自由练习
提醒：提前30分钟

⚠️ 以下人员无法精确匹配到群成员，将仅作为文本展示，不能 @ 或私聊提醒：
- 制作组

如确认发布，请发送：
#确认发布 P001

取消请发送：
#取消发布 P001
```

| 命令 | 说明 |
|---|---|
| `#确认发布 P001` | 正式发送通知并创建提醒任务 |
| `#取消发布 P001` | 放弃本次发布 |
| `#确认发布` | 省略 ID 时确认你最近一次预览 |

- 只有返回预览时才需要确认；直接发布时没有 `P001`；
- 预览 30 分钟内有效；
- 只有发起预览的人可以确认 / 取消；
- 开始时间已过仍可发布，但不会发送提醒；
- 已错过的提醒不会补发。

> 建议：如果剧组希望“所有通知都必须人工过目”，设置 `#配置 发布确认=开`。

### 7.5 @全体成员

- 人员字段写 `@全体成员` → 全体成员都是参与对象；
- `通知范围=全体成员` → 参与人员照常通知，但提醒时提醒全群；
- 机器人是群管理员 → 发送真正的 `@全体成员`；
- 机器人不是群管理员 → 自动降级为逐个 @：默认只 @ 参与人员，可配置为 @ 全体群成员，并自动分段发送；
- 不在人员字段中的 `@全体成员` 只表示提醒全群，不参与人员匹配。

### 7.6 文本人员提示

无法匹配到群成员的名称会作为文本人员，预览中会明确提示，确认后仍可发布；文本人员不会被 @，也不会收到私聊提醒。

## 8. 查询

### 8.1 群内查询本剧组

```text
#排练列表              # 未来排练（默认）
#排练列表 本周         # 本周一至周日
#排练列表 下周
#排练列表 全部
#排练历史              # 最近 10 条
#排练历史 20           # 最近 20 条（最多 50）
#排练详情 3            # 编号 3 的完整通知
```

- 演员可以查看本剧组所有通知，不限于本人参与的；
- 已取消的排练会标注「（已取消）」，已结束标注「（已结束）」。

### 8.2 私聊查询本人安排

```text
#我的排练
#我的排练 今天
#我的排练 本周
#我的排练 下周
#我的排练 未来
#我的排练 历史
#我的排练 全部
```

- 聚合你在多个剧组的安排，按时间轴排序；
- 显示剧组名称、时间、地点、内容、你的备注标签；
- 不显示他人 QQ 号；
- 在群内发送 `#我的排练` 也只会返回你自己的安排，并提示建议私聊查询。

> 全体成员通知（`人员=@全体成员`）会展示给在该剧组有角色或演员记录的用户。

## 9. 修改与重新发布

### 9.1 修改

```text
#排练修改 3 时间=周五8~10
#排练修改 3 地点=二排
#排练修改 3 人员=@张三 @李四
#排练修改 3 内容=1. 开场 2. 走位
#排练修改 3 备注=自愿参加
#排练修改 3 提醒=30,10
#排练修改 3 提醒=关闭
```

- 可只填要修改的字段；
- 不带字段发送 `#排练修改 3` 可查看当前通知与修改模板；
- 修改先进入预览：

```text
【修改预览】
编号：3
标题：#排练通知
原时间：2026-11-08 周日 19:00-22:00
时间：2026-11-13 周五 19:00-22:00
...
如确认修改，请发送：
#确认修改 M001
```

- `#确认修改 M001` 保存，**不会自动重发**；
- `#取消修改 M001` 放弃；
- 保存后提醒任务同步更新；已发送的提醒不会重复发送。

### 9.2 重新发布

```text
#排练重发 3
#确认重发 R001
```

- 重发前必须预览确认；
- 正式消息标题仍为 `#排练通知`，正文包含「以下为更新后的排练通知」；
- 重发后提醒任务同步更新；
- 已取消的排练不能重发。

> 系统不保留通知历史版本，修改直接覆盖当前值；审计日志记录修改动作。

## 10. 取消与删除

### 10.1 取消排练

```text
#取消排练 3
```

机器人询问是否发布取消通知：

```text
#确认取消 3 通知=是
#确认取消 3 通知=否
```

- 状态变为已取消，未发送提醒全部停止；
- 选择「是」时在群内发送：

```text
#排练取消通知
原定于11月13日 周五 19:00-22:00的排练已取消。
地点：一排
```

> 私聊管理多个剧组时，确认命令需带剧组名：
> `#确认取消 3 通知=是 剧组=剧组A`。

### 10.2 删除排练（软删除）

```text
#删除排练 3
#确认删除 3
#取消删除 3
```

- 默认软删除，普通成员不可见；
- 提醒停止；
- 管理员可物理删除：

```text
#彻底删除 3
```

> 私聊管理多个剧组时：`#确认删除 3 剧组=剧组A`。

## 11. 时间格式

### 11.1 支持的日期

```text
今天 / 明天 / 后天 / 大后天
周一 ~ 周日
星期一 ~ 星期日
礼拜一 ~ 礼拜天
本周五 / 下周五
10.21
10/21
10月21日
2026-11-13
2026年11月13日
```

### 11.2 支持的时间

```text
晚上8:30~10:00
晚8:30~10:00
下午2点~4点
上午9点~11点
19:30-21:00
7~10
周五7~10
周一晚8:30~10:00
明天下午2点~4点
```

- 分隔符可用 `~`、`-`、`～`、`至`、`到`；
- `半` 表示 30 分（`8点半`）；
- 单写一个开始时间时，默认按 2 小时计算结束时间，并在预览中提示。

### 11.3 模糊时间规则

| 输入 | 规则 | 结果示例 |
|---|---|---|
| `7~10` | 开始小时 < 晚上阈值（默认 9）按晚上解释 | 19:00-22:00 |
| `8~11` | 同上 | 20:00-23:00 |
| `8~1` | 结束早于开始 → 跨天 | 20:00-次日 01:00 |
| `9~11` | 9 不小于阈值 → 按 24 小时制 | 09:00-11:00 |
| `晚上8:30~10:00` | 显式晚上 | 20:30-22:00 |
| `下午2点~4点` | 显式下午 | 14:00-16:00 |
| `周五7~10`（周六发布） | 下一个周五 | 下周五 19:00-22:00 |
| `周一晚8:30`（周一 21:00 发布） | 下一次出现 | 下周一 20:30，并提示已顺延 |
| `10.21`（今年已过） | 顺延到明年 | 明年 10 月 21 日，并提示 |
| `今天7~10`（已过） | 保留今天 | 预览提示开始时间已过、不提醒 |

晚上阈值可通过 `#配置 晚上阈值=10` 修改（按剧组生效）。

### 11.4 提醒与开始时间

- 距离开始不足提醒时间：仍可发布，只发送尚未错过的提醒；
- 已开始的排练：仍可发布，不会发送提醒；
- 预览会逐条提示顺延、跨天、跨年、错过提醒等情况。

## 12. 人员、标签与 @

### 12.1 备注标签写法

以下写法等价，标签为「湖区」：

```text
湖区@张三
@张三(湖区)
@张三（湖区）
@张三[湖区]
```

默认显示为 `@张三`；开启 `显示标签` 后显示 `@张三（湖区）`。

### 12.2 文本人员

```text
人员=@张三 制作组 灯光组
```

`制作组`、`灯光组` 仅作为展示对象，不能 @、不能私聊提醒；预览会给出提示。

### 12.3 去重

重复 @ 会自动去重；同一个人不会重复提醒。

## 13. 提醒

### 13.1 剧组默认提醒

```text
#提醒默认 30
#提醒默认 60,30,10
#提醒默认 关闭
```

- 默认提前 30 分钟；
- 支持多个提醒时间，按从早到晚触发；
- 单条排练可用 `#排练修改 3 提醒=...` 覆盖。

### 13.2 私聊提醒

```text
#配置 私聊提醒=开
#配置 私聊提醒=关
```

开启后，提醒会同时私聊所有已匹配 QQ 的参与人员；私聊失败会写入审计日志。文本人员不会收到私聊。

> `人员=@全体成员` 的通知只发送群提醒，不逐个私聊，避免大规模私聊风控。

### 13.3 提醒消息示例

```text
#排练提醒
还有30分钟开始
时间：今天 19:00-22:00
地点：一排
内容：
1. 福临门开场和声
2. 一念一宇宙

请相关成员准时参加：
@冯然 @关静一
```

私聊提醒会带上剧组名：

```text
【排练提醒】剧组A
还有30分钟开始
时间：今天 19:00-22:00
地点：一排
内容：福临门合排
```

### 13.4 可靠性

- 提醒任务持久化，机器人重启后自动恢复；
- 同一提醒不会重复发送；
- 发送失败自动重试（默认最多 3 次）；
- 修改时间 / 提醒后任务同步更新；
- 取消或删除后提醒停止；
- 进程在发送过程中崩溃：该次提醒标记失败、不自动重发，优先保证不重复打扰。

## 14. 配置

### 14.1 查看

```text
#配置查看
```

### 14.2 修改剧组配置

```text
#配置 默认提醒=60,30
#配置 私聊提醒=开
#配置 晚上阈值=9
#配置 显示标签=开
#配置 显示空字段=开
#配置 发布确认=开
#配置 降级范围=参与人员
#配置 降级范围=全体成员
#配置 时区=Asia/Shanghai
```

| 配置项 | 说明 | 默认 |
|---|---|---|
| 默认提醒 | 提前多少分钟提醒，支持多个 | 30 |
| 私聊提醒 | 是否私聊参与人员 | 关 |
| 晚上阈值 | 开始小时小于该值时按晚上解释 | 9 |
| 显示标签 | 通知中是否显示备注标签 | 关 |
| 显示空字段 | 是否显示「暂无」 | 关 |
| 发布确认 | 开=总是预览；关=无问题直接发布 | 关 |
| 降级范围 | 非群管理员时逐个 @ 的目标 | 参与人员 |
| 时区 | 剧组时区 | Asia/Shanghai |

### 14.3 全局配置（管理员）

```text
#全局配置查看
#全局配置 发送间隔=1.0
#全局配置 重试次数=3
#全局配置 提醒宽限=90
#全局配置 分段人数=20
```

| 配置项 | 说明 | 默认 |
|---|---|---|
| 发送间隔 | 两条消息之间的最小间隔（秒） | 1.0 |
| 重试次数 | 提醒发送失败最多重试次数 | 3 |
| 提醒宽限 | 触发时间超过多少秒视为错过 | 90 |
| 分段人数 | 逐个 @ 时每条消息最多 @ 人数 | 20 |

## 16. 常见错误提示

| 提示 | 原因 | 处理 |
|---|---|---|
| 时间无法识别 | 时间写法不在支持范围 | 使用 `周五7~10`、`明天下午2点~4点` 等 |
| 请填写参与人员 | 缺少人员字段 | 补 `人员=@张三` |
| 以下人员无法精确匹配到群成员 | 文本人员无法 @ | 确认后仍可发布；如需 @ 请添加演员 / 使用 @ |
| 当前机器人不是群管理员 | 无法真正 @全体成员 | 将机器人设为群管理员，或接受逐个 @ 降级 |
| 该排练开始时间已过，将不会发送提醒 | 发布时间晚于开始时间 | 确认是否仍需发布 |
| 该日期今年已过，已按下一年处理 | 无年份日期已过 | 在预览中确认年份 |
| 预览已过期 | 超过 30 分钟 | 重新发送发布 / 修改命令 |
| 只有发起人可以确认 | 其他人尝试确认 | 由发起人确认，或重新发起 |
| 你管理多个剧组 | 私聊管理命令未指定剧组 | 用 `剧组=名称` 指定 |
| 你参与了多个剧组 | 私聊查询命令未指定剧组 | 用 `剧组=名称` 指定 |
| 你还没有管理任何剧组 | 无私导 / 副导演角色 | 联系管理员授权 |
| 权限不足 | 角色不够 | 联系导演 / 管理员授权 |
| 未找到编号 N 的排练 | 编号错误或已删除 | `#排练列表` 查看编号 |
| 本群尚未绑定剧组 | 未初始化 | 管理员 `#初始化剧组 名称` |
| 该剧组已解绑 | 已解绑 | 联系管理员重新初始化 |
