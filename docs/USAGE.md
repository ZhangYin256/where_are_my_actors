# 使用手册

面向导演、副导演、管理员和演员的完整使用教程。命令细节见 [COMMANDS.md](COMMANDS.md)，完整模拟器对话见 [DEMO-TRANSCRIPT.md](DEMO-TRANSCRIPT.md)。

---

## 1. 角色与初始准备

### 1.1 角色

| 角色 | 能做什么 |
|---|---|
| 管理员 | 所有剧组的最高权限：授权导演 / 管理员、解绑、全局配置、彻底删除 |
| 导演 | 本剧组通知、演员、提醒配置；可授权副导演；群主 / 群管理员自动获得 |
| 副导演 | 与导演相同的日常管理权限，但不能授权任何角色 |
| 演员 | 接收通知与提醒、查看本剧组排练、私聊查询本人安排 |

同一个人可以在不同剧组拥有不同角色；管理员、导演、副导演也可以作为演员参加排练。

### 1.2 部署完成后第一次配置

1. 把机器人 QQ 拉进剧组群；
2. 如需真正 `@全体成员`，在 QQ 群中把机器人设为**管理员**；
3. 管理员或群主在群内发送：

```text
#初始化剧组 某某剧组
```

也可以由管理员**私聊**初始化（不在群里刷屏，需提供群号）：

```text
#初始化剧组 某某剧组 群号=123456789
```

机器人会回复剧组信息、你的角色、默认提醒等。群主 / 群管理员自动成为导演。

4. 导演 / 管理员添加协作者：

```text
#授权副导演 @李四
```

5. （可选）添加演员表，便于用别名 / 文本名匹配：

```text
#添加演员 @张三
#添加演员 制作组
#演员别名 @张三 小张
#演员标签 @张三 湖区
```

> 演员表不是发布通知的前置条件。每次排练可以直接 @ 任意群成员。

### 1.3 私聊管理（减少群消息）

日常管理可以尽量在私聊完成：

```text
#剧组列表                          查看自己参与 / 管理的剧组、群号、角色
#初始化剧组 某某剧组 群号=123456789  管理员私聊初始化
#发布排练 剧组=某某剧组 ...         私聊发布
#排练修改 3 地点=二排 剧组=某某剧组
#排练重发 3 剧组=某某剧组
#确认取消 3 通知=是 剧组=某某剧组
#配置 默认提醒=60,30 剧组=某某剧组
#同步成员 剧组=某某剧组
#审计日志 20 剧组=某某剧组
```

- 管理命令只在你担任导演 / 副导演的剧组中自动选择；恰好管理一个时可省略 `剧组=`；
- 查询命令按你参与或管理的剧组判断，多个时需要 `剧组=`；
- `#我的排练` 不需要剧组，自动聚合所有剧组。

> 管理员初始化被拒绝时，先发 `#剧组列表` 查看“全局管理员：是/否”，
> 再检查 `.env` 的 `REHEARSAL_ADMINS`，必要时用
> `docker compose exec -T bot python scripts/grant_admin.py <QQ>` 恢复。

## 2. 发布第一条排练通知

### 2.1 发送发布命令

```text
#发布排练
时间=周五7~10
地点=一排
人员=@冯然 @关静一 制作组
内容=
1. 福临门开场和声
2. 一念一宇宙
备注=其他演员可以来自由练习
```

要点：

- `时间`、`人员` 必填；地点、内容、备注可空；
- 字段分隔符 `=`、`：`、`:` 都可以；
- 内容多行时会保留并自动编号；
- 文本人员（如“制作组”）会被明确提示不能精确提醒。

### 2.2 机器人如何响应

默认配置 `发布确认=关`，机器人会先检查通知是否存在风险：

- **没有任何问题**（人员都能匹配、时间无顺延、未错过提醒等）：
  直接发送正式通知，并回复：

```text
✅ 已发布排练通知（编号 1）。
时间：11月13日 周五 19:00-22:00
提醒：提前30分钟
发送 #排练详情 1 查看详情。
```

- **存在需要注意的问题**：
  返回预览，等待你确认。上面的示例包含文本人员“制作组”，因此会先预览：

```text
【发布预览】
标题：#排练通知
时间：2026-11-13 周五 19:00-22:00
地点：一排
人员：@冯然 @关静一 制作组
内容：
1. 福临门开场和声
2. 一念一宇宙
备注：其他演员可以来自由练习
提醒：提前30分钟

⚠️ 以下人员无法精确匹配到群成员，将仅作为文本展示，不能 @ 或私聊提醒：
- 制作组

如确认发布，请发送：
#确认发布 P001

取消请发送：
#取消发布 P001
```

需要预览的典型情况：

- 时间被自动顺延（下一周 / 下一年 / 跨天）；
- 未写结束时间（默认按 2 小时）；
- 开始时间已过；
- 已错过部分提醒；
- 有文本人员无法精确匹配；
- `@全体成员` 但机器人不是群管理员。

重点检查：

- 时间是否符合预期（尤其是“周五”“明天”这类模糊表达）；
- 是否有“已按下一年处理”“按下一周处理”“跨天处理”等提示；
- 文本人员是否正确；
- 提醒时间是否符合剧组习惯。

如果剧组希望**所有通知都必须人工过目**：

```text
#配置 发布确认=开
```

改回默认：

```text
#配置 发布确认=关
```

### 2.3 确认发布

只有出现预览时才需要确认：

```text
#确认发布 P001
```

群里会收到正式通知：

```text
#排练通知
时间：11月13日 周五 19:00-22:00
地点：一排
人员：@冯然 @关静一 制作组
内容：
1. 福临门开场和声
2. 一念一宇宙
备注：其他演员可以来自由练习
```

同时系统创建提醒任务。到排练前 30 分钟，群里会收到：

```text
#排练提醒
还有30分钟开始
时间：今天 19:00-22:00
地点：一排
内容：
1. 福临门开场和声
2. 一念一宇宙

请相关成员准时参加：
@冯然 @关静一
```

> 如果发现写错了，可以发送 `#取消发布 P001`（在确认之前），或发布后使用 `#排练修改`。

## 3. 查看排练

### 3.1 群内查看

所有成员都可以查看本剧组通知：

```text
#排练列表            # 未来
#排练列表 本周       # 本周一至周日
#排练列表 下周
#排练列表 全部
#排练历史            # 已结束 / 过去的排练
#排练详情 3
```

### 3.2 私聊查看个人安排

私聊机器人：

```text
#我的排练
#我的排练 今天
#我的排练 本周
#我的排练 历史
```

返回示例：

```text
【你的排练安排】
2026-11-08 周日
19:00-22:00 剧组A
地点：一排
内容：福临门合排

2026-11-10 周二
20:00-21:30 剧组B
地点：二楼排练厅
内容：唱段练习
```

- 跨剧组聚合；
- 按时间轴排序；
- 显示剧组名与你的备注标签；
- 不显示他人 QQ。

> 私聊执行**管理命令**（发布、修改、演员、配置等）时，只在你担任导演 / 副导演的剧组中自动选择；
> 恰好管理一个时可省略剧组，管理多个时才需要 `剧组=名称`。
> 查询类命令（排练列表、详情等）按你参与或管理的剧组判断，多个时同样需要指定。

## 4. 修改与重新发布

### 4.1 修改

只需填写要改的字段：

```text
#排练修改 3 地点=二排
```

或一次改多个：

```text
#排练修改 3
时间=周五8~11
地点=二排
备注=请相关成员注意地点变化
```

系统返回修改预览，确认：

```text
#确认修改 M001
```

修改保存后**不会自动重发**。机器人会提示：

```text
修改已保存。
如需在群内重新发布，请发送：
#排练重发 3
```

### 4.2 重新发布

```text
#排练重发 3
```

确认预览后：

```text
#确认重发 R001
```

群内收到：

```text
#排练通知
以下为更新后的排练通知
时间：11月13日 周五 20:00-23:00
地点：二排
...
```

- 提醒任务同步更新；
- 已发送过的提醒不会重复发送；
- 不保留历史版本，审计日志记录修改动作。

## 5. 取消与删除

### 5.1 取消（推荐）

```text
#取消排练 3
```

机器人询问是否发布取消通知：

```text
#确认取消 3 通知=是
```

群里收到：

```text
#排练取消通知
原定于11月13日 周五 19:00-22:00的排练已取消。
地点：一排
```

- 已取消的排练仍可在列表中看到（标注「已取消」），不能修改 / 重发；
- 未发送提醒全部停止。

如果只是内部取消、不惊动群：

```text
#确认取消 3 通知=否
```

### 5.2 删除

```text
#删除排练 3
#确认删除 3
```

- 默认软删除，普通成员看不到；
- 管理员如需物理删除：

```text
#彻底删除 3
```

> 删除不可恢复，操作前请确认编号。取消 ≠ 删除：取消保留记录，删除对普通成员隐藏。

## 6. 演员、别名与标签

### 6.1 为什么需要演员表

- 允许用别名（如“小张”）匹配到 QQ 成员；
- 记录常用备注标签（如“湖区”“牌区”）；
- 支持文本人员（如“制作组”）作为展示对象。

### 6.2 常用命令

```text
#添加演员 @张三
#添加演员 制作组
#演员列表
#演员别名 @张三 小张
#演员标签 @张三 湖区
#移除演员 @张三
```

### 6.3 标签在通知中的显示

默认不显示标签：

```text
人员：@张三 @李四
```

开启后：

```text
#配置 显示标签=开
```

显示为：

```text
人员：@张三（湖区） @李四（牌区）
```

标签也会记录到本次排练的参与记录中，私聊查询时会显示。

## 7. 提醒配置

### 7.1 默认提醒

```text
#提醒默认 30          # 默认
#提醒默认 60,30,10    # 多个提醒
#提醒默认 关闭        # 关闭默认提醒
```

### 7.2 单条排练提醒

```text
#排练修改 3 提醒=30,10
#排练修改 3 提醒=关闭
```

### 7.3 私聊提醒

```text
#配置 私聊提醒=开
```

开启后，已匹配 QQ 的参与人员会同时收到私聊：

```text
【排练提醒】剧组A
还有30分钟开始
时间：今天 19:00-22:00
地点：一排
内容：福临门合排
```

文本人员不会收到私聊；`@全体成员` 通知只发群提醒，不逐个私聊。

### 7.4 开始时间不足

- 如果发布时距离开始不足提醒时间：只发布通知，已错过的提醒不补发；
- 如果开始时间已过：仍可发布，但不会发送提醒；
- 预览会明确提示。

## 8. 权限管理

### 8.1 群主 / 群管理员自动导演

- 群主、QQ 群管理员自动获得该剧组导演角色；
- 系统在收到消息、群管理变更通知、定时同步时维护；
- 失去群管理身份后自动撤销，手动授予的副导演 / 导演不受影响；
- 管理员可发送 `#同步成员` 立即全量同步。

### 8.2 授权副导演

导演或管理员：

```text
#授权副导演 @李四
#取消副导演 @李四
```

### 8.3 授权导演 / 管理员

仅管理员：

```text
#授权导演 @王五
#取消导演 @王五
#授权管理员 123456789
#取消管理员 123456789
```

- 不能取消唯一管理员；
- 管理员是全局角色，在所有剧组生效；
- 群主 / 群管理员的自动导演无法手动取消，需先调整其群身份。


```text
【审计日志】
```

## 11. 常见工作流

### 11.1 每周固定排练

1. 发布下周五的通知；
2. 设置 `#提醒默认 60,30`；
3. 每周复制上一条通知，修改时间即可：

```text
#发布排练
时间=下周五7~10
地点=一排
人员=@张三 @李四
内容=常规排练
```

### 11.2 临时加排

```text
#发布排练
时间=今天8~10
地点=二排
人员=@张三 @李四
备注=临时加排，自愿参加
提醒=10
```

### 11.3 地点变更

```text
#排练修改 3 地点=二排
#确认修改 M001
#排练重发 3
#确认重发 R001
```

### 11.4 暴雨取消

```text
#取消排练 3
#确认取消 3 通知=是
```

### 11.5 演员查询自己的安排

私聊：

```text
#我的排练 本周
```

## 12. 最佳实践

1. **机器人使用专用 QQ**，不要用主账号；
2. **把机器人设为群管理员**，否则无法真正 @全体成员；
3. **重要 / 复杂通知先预览**：可临时 `#配置 发布确认=开` 强制预览，确认前可 `#取消发布`；
4. **用编号沟通**：`#排练详情 3`、`#排练修改 3`，避免“那条通知”歧义；
5. **地点 / 内容为空就不用写**，或写 `暂无`；
6. **给常用人员设置别名与标签**，查询结果更清晰；
7. **定期备份数据库**（见 [OPERATIONS.md](OPERATIONS.md)）；
8. **不要频繁群发 / 多次重发**，避免 QQ 风控；
9. 修改后**记得手动重发**，系统不会自动重发；
10. 取消优先于删除，保留记录便于追溯。

## 13. 遇到问题

| 问题 | 处理 |
|---|---|
| 发布没有反应 | 确认命令以 `#` 开头、群已初始化剧组、你有发布权限 |
| 时间解析不对 | 查看预览提示；用更明确的写法如 `周五19:00-22:00` |
| 文本人员不能 @ | 正常行为；如需 @，请 @ 群成员或先添加演员 |
| 收不到提醒 | 检查开始时间是否已过、提醒是否关闭、`#配置查看`、机器人是否在线 |
| 想改机器人昵称 / 群名片 | 在 QQ 中修改即可，不影响功能 |
| 想换群 | 一个群只能绑定一个剧组；新群需重新 `#初始化剧组` |
| 忘记命令 | `#帮助` 或 `#帮助发布排练` |

更多错误对照见 [COMMANDS.md#16-常见错误提示](COMMANDS.md#16-常见错误提示)，运维排查见 [OPERATIONS.md](OPERATIONS.md)。
